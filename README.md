# Supply Chain Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing supply chain operations using Power BI. The dashboard provides insights into product performance, shipping operations, manufacturing processes, and quality metrics to support data-driven business decisions.

## Objectives
- Analyze overall supply chain performance.
- Evaluate product-level performance.
- Analyze shipping operations and shipping costs.
- Examine manufacturing performance and quality metrics.
- Identify key business insights.
- Provide actionable business recommendations.

## Tools & Technologies
- Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## Dashboard Pages

### 1. Overview
Provides an overview of key supply chain performance metrics.

### 2. Product Analysis
Analyzes product-related performance and key metrics.

### 3. Shipping Analysis
Evaluates shipping-related metrics and transportation performance.

### 4. Manufacturing & Quality Analysis
Analyzes manufacturing operations and quality-related metrics.

### 5. Business Insights
Highlights key findings and observations from the analysis.

### 6. Business Recommendations
Provides recommendations to improve supply chain operations and business performance.
